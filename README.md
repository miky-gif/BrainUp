# BrainUp Technology - Site Web Professionnel

Site web moderne et professionnel pour BrainUp Technology, centre de formation en informatique basé à Bafia, Cameroun.

## 🚀 Fonctionnalités

- **Page d'accueil** : Présentation complète avec hero section, services, témoignages, statistiques
- **Système d'inscription** : Formulaire complet d'inscription aux formations avec validation
- **Catalogue de formations** : Toutes les formations avec filtres et système de recherche
- **Plateforme e-learning** : Espace membre sécurisé avec cours, vidéos, progression
- **Gestion des concours** : Inscription et suivi des concours avec lots à gagner
- **Boutique en ligne** : Vente d'équipements informatiques
- **Espace administrateur** : Dashboard complet pour gérer le site
- **Blog** : Actualités et conseils tech

## 🛠️ Technologies

- **React 18** avec Hooks
- **React Router** pour la navigation
- **Tailwind CSS** pour le styling
- **Framer Motion** pour les animations
- **React Hook Form** pour la gestion des formulaires
- **Lucide React** pour les icônes
- **Vite** comme bundler

## 📦 Installation

```bash
# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev

# Build pour la production
npm run build

# Prévisualiser le build
npm run preview
```

## 🌐 Structure du Projet

```
src/
├── components/          # Composants réutilisables
│   ├── layout/         # Header, Footer, Navigation
│   ├── common/         # Boutons, Cards, Modals
│   └── forms/          # Composants de formulaires
├── pages/              # Pages de l'application
│   ├── Home/           # Page d'accueil
│   ├── Formations/     # Catalogue et détails
│   ├── Inscription/    # Inscription aux formations
│   ├── Dashboard/      # Espace étudiant
│   ├── Concours/       # Page concours
│   ├── Boutique/       # Boutique en ligne
│   ├── Contact/        # Page contact
│   ├── Blog/           # Blog et actualités
│   └── Admin/          # Espace administrateur
├── contexts/           # Context API pour l'état global
├── hooks/              # Custom hooks
├── utils/              # Fonctions utilitaires
├── data/               # Données statiques
└── styles/             # Styles globaux
```
